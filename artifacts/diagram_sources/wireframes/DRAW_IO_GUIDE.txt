STORYBOARD + WIREFRAME GUIDE FOR draw.io
================================================================================

HOW TO OPEN:
  1. Go to https://app.diagrams.net
  2. File > Open from > Device
  3. Select any .drawio file from this folder
  4. Edit labels, colours, positions
  5. File > Export as > PNG / PDF

FILES:
  UC01_storyboard.drawio   UC01_lowfi.drawio   UC01_highfi.drawio
  UC02_storyboard.drawio   UC02_lowfi.drawio   UC02_highfi.drawio
  UC03_storyboard.drawio   UC03_lowfi.drawio   UC03_highfi.drawio
  UC04_storyboard.drawio   UC04_lowfi.drawio   UC04_highfi.drawio

COLOURS (high-fi only):
  Header / primary button : #176B53
  Text                    : #18332F
  Pending / warning       : #D97706
  Surface                 : #EAF3EE
  Low-fi                  : black / white / grey only

MANUAL BUILD (if you prefer from scratch):

STORYBOARD = 6 rounded rectangles in a row
  - Black header with step title
  - Circle with step number
  - 3 short text lines

LOW-FI / HIGH-FI = 3 phone frames side by side
  - Rounded rectangle (phone body)
  - Top bar = screen title
  - Content: labels, grey placeholder boxes, buttons
  - Bottom home indicator bar

UC01 flow: Assigned Route → Active Patrol → Result (PENDING/Synced)
UC02 flow: New Incident → Review → Saved PENDING / Submitted
UC03 flow: Alert detail → Assign Officer → Status (Awaiting Ack / Ack)
UC04 flow: Filters → Report Result → Export
