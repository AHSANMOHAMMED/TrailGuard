# UC01 Demo Script — Ranger Patrol (Sureka)

1. Sign in as **Ranger** (`4021`).
2. Open **Ranger Patrol** → **Start Patrol**.
3. Wait until coverage shows **Route covered** (demo pace ~15–20 s).
4. Optionally **Mark Waypoint** then **Undo** from the toast (R-10).
5. Toggle **Offline**, complete if already covered, or stay online and **Complete Patrol**.
6. Confirm summary shows **Synchronized** after Sync upserts the same patrol id.
7. Open the sync queue badge — it stays clear when nothing is PENDING/FAILED.

Offline alternative: finish while Offline → record stays PENDING → go Online → auto drain.
